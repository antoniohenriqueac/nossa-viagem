# Nossa viagem

Site estático (Vite + Preact) com o roteiro de Tailândia e Bali — 25 de janeiro a 17 de fevereiro.

Publicado em GitHub Pages: https://antoniohenriqueac.github.io/nossa-viagem/

## Desenvolvimento

```bash
npm install
npm run dev
```

Build (mesmo `BASE_PATH` do Pages):

```bash
BASE_PATH=/nossa-viagem/ npm run build
npm run preview
```

## Foto do casal

A foto do casal fica em **`public/photos/nos.jpg`**. Para trocar depois, substitua o arquivo mantendo o mesmo nome.

## Fotos dos destinos

Imagens locais em `public/destinations/`. Créditos em `ATTRIBUTION.md`.
